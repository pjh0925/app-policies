## Adding an app

1. Create `<app-slug>/privacy-policy/index.html` and `<app-slug>/support/index.html`
   (plus `ko/index.html` in each if needed).
2. Add a link to `index.html` and a row to the table above.

URLs are registered in App Store Connect and Google Play, so do not rename
existing folders.
